# Data Dictionary

This document explains all data files in the project and their purposes.

**Last Updated:** January 21, 2026

---

## Folder Structure

```
data/
├── primary/                # THE canonical dataset
├── reference/              # Lookup tables and state tracking
└── derived/
    ├── visualizations/     # Files for Flourish, DataWrapper, etc.
    └── exports/            # JSON/API exports
```

---

## Primary Data

### `data/primary/disputes_enriched.csv`
**THE canonical dataset. All other files derive from this.**

| Attribute | Value |
|-----------|-------|
| Records | 203 disputes |
| Columns | 57 fields |
| Date Range | 2021-2025 |
| Last Updated | January 2026 |
| Mean Completeness | 0.77 |

**Use this file for:**
- All analysis and reporting
- Source of truth for dispute data
- Input to visualization scripts

See [SCHEMA.md](SCHEMA.md) for complete field documentation.

### `data/primary/patient_estimation_report.json`
Small report file tracking patient estimation calculations.

## Reference Data

### `data/reference/health_systems_reference.json`
Lookup table of ~70+ health systems with enrichment data.

**Fields include:**
- Name variants (for matching)
- HQ coordinates
- Ownership type
- Academic status
- Hospital count
- Annual revenue
- Footprint states

**Used by:** Enrichment scripts to populate system fields

### `data/reference/payer_market_reference.json`
Market data for major payers.

**Used by:** Patient estimation calculations

### `data/reference/enrichment_state.json`
Tracks enrichment progress.

**Fields:**
- `last_processed_id` - Last dispute processed
- `total_disputes` - Total count
- `enriched_count` - How many enriched
- `map_ready_count` - How many have coordinates
- `last_run` - Timestamp

## Derived Data

### Visualizations (`data/derived/visualizations/`)

#### `datawrapper_range_plot_simple.csv`
**Purpose:** DataWrapper range plot visualization (CURRENT VERSION)

Simplified timeline showing dispute start/end dates as horizontal bars.

**Generated by:** `scripts/visualization/regenerate_datawrapper_simple.py`

**Columns:**
- `dispute_name` - Display label
- `start_date` - Beginning of dispute
- `end_date` - Resolution or current date
- `outcome_status` - For color coding
- `patients_affected` - For sizing/filtering

#### `disputes_flourish_timeslider.csv`
**Purpose:** Flourish time-slider visualization

Transforms the canonical data into Flourish's required format with 20 quarter columns (2021 Q1 through 2025 Q4) showing dispute status at each time point.

**Generated by:** `scripts/visualization/create_flourish_timeslider.py`

#### `disputes_map_ready.csv`
**Purpose:** Flourish map visualization

Subset of disputes that have valid coordinates (lat/lon). Currently ~82 records.

**Key columns for Flourish:**
- `system_hq_lat` / `system_hq_lon` - Point location
- `patients_affected` - Bubble size
- `outcome_status` - Color coding
- `dispute_name` - Label/tooltip

#### `timeline_events.csv`
**Purpose:** Animation/timeline visualization

Flattened event format where each row is a single event (dispute goes public, goes OON, resolves, etc.).

**Columns:**
- `dispute_id` - Links back to main data
- `event_date` - When event occurred
- `event_type` - `dispute_public`, `oon_effective`, `resolution_date`
- `event_description` - Brief description

**Records:** 264 events from 203 disputes

### Exports (`data/derived/exports/`)

#### `disputes_enriched.json`
**Purpose:** Airtable import / API consumption

JSON array format of the canonical CSV, ready for database import.

### Other Derived Files

#### `system_enrichment_database.csv`
**Purpose:** System lookup table (in main `data/derived/`)

Database of enriched system characteristics (beds, revenue, margins, etc.) for 141 systems.

#### `disputes_dashboard.html`
**Purpose:** Standalone HTML dashboard (in main `data/derived/`)

Self-contained visualization dashboard.

## Input Data

### `input/disputes_to_enrich.csv`
**Purpose:** Original seed data

The starting point containing 221 raw dispute records before enrichment. Kept for reference but the canonical `disputes_enriched.csv` supersedes this.

## Working Files

### `worksheets/search_query_worksheet.csv`
**Purpose:** Manual research tracking

149 disputes with pre-generated search queries for manual enrichment. Columns include URLs, research notes, and data to extract.

**Used with:** `scripts/enrichment/process_worksheet_results.py`

## File Naming Conventions

- **Primary data:** `disputes_enriched.csv` - the canonical dataset
- **Visualization outputs:** Prefixed with tool name (`datawrapper_`, `flourish_`, etc.)
- **Reference data:** Descriptive names in `data/reference/`
- **Backups:** Include timestamp or purpose in filename
- **Scripts:** Organized by function in subdirectories
